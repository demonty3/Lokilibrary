Frozen operationalisation (settled with Harry before the murals existed):

  • The task: pair each mural (1–4) to one library (A–D). Each library is used exactly once.
  • PASS = 2 or more of 4 correct (random pairing gets 1 right on average). Kill fires at 1 or fewer.
  • On the record: a random pairer still scores 2+ about 29% of the time, so a pass is suggestive, not conclusive. 3 of 4 is mathematically impossible; 4 of 4 has a ~4% false-pass rate.

Presentation protocol (recorded before observation): all four murals were cold-authored by context-cold agents, one per library profile, each given only the blueprint and its own profile; every mural passed the full gate with zero hand-fixes. All four were shot mounted on the same wing (d1) in one headless-Chrome window in a randomised order, so the frame, the land beneath, and the cartouche (which names that wing's sample flagship, unrelated to every profile) are constant across shots and carry no pairing signal. One fake library deliberately owns a game the real library also owns, with the opposite engagement, so game recognition alone cannot settle every pair.
